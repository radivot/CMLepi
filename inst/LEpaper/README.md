R scripts used in 
**Diagnosis of Chronic Myeloid Leukemia at a Mean Age of 59 Implies a Mean Loss of Roughly 8 of 24 Years of Life in the United States**
First run the scripts on the main [page](https://github.com/radivot/CMLepi). Then run `mkMorts.R`. 
It should then be possible to run any other script, save that `S7_mkhBack.r` must be run before `S7_RP.R`.

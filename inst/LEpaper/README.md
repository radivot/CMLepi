# Diagnosis of Chronic Myeloid Leukemia at a Mean Age of 59 Implies a Mean Loss of Roughly 8 of 24 Years of Life in the United States

This folder holds the scripts that made this paper's figures. To setup SEER and mortality data please read and 
run the scripts on the main `README.md` [page](https://github.com/radivot/CMLepi).  This will take care of  
`mkSEER.R` and Figures 1, 2 and 4. Next run `mkMorts.R`. It should then be possible to run all of the other scripts, with 
one exception: before running `S7_RP.R` you must first run `S7_mkhBack.r`.
